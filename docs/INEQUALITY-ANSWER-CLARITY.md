# Solve inequalities: clear task and answer format

The teacher identified that “solve over the real numbers; write a statement describing all its solutions” plus “Number in the solution” was confusing. The revised task directly asks students to solve for the variable, with the inequality on its own line. The answer builder follows normal mathematical order: variable, chosen sign, entered number. It displays the complete student answer as it changes. It does not reveal a correct answer before checking or submitting mastery.

For the flagged budget practice, students read that the setup costs $18, each session costs $6, and the budget is $90. They solve 18 + 6x ≤ 90 for x. A correct answer is x ≤ 12, meaning at most 12 sessions; it is not a request to name just any affordable number such as 10. Existing instruction still distinguishes the algebraic solution from nonnegative whole session counts in context.

All eight solve-an-inequality items now use direct prompts and a separately displayed inequality, including both mastery forms. Graphing prompts say “on the number line.” Saved answers use the same boundary/operator format and lesson revision, so existing student progress remains compatible. The answer key, scoring, graphing requirements and independent mastery policy are unchanged.

This supports Missouri 7.EEI.B.4c: writing, solving and graphing one-variable linear inequalities, with contextual interpretation. Source: DESE Grade 7 expanded expectations, page 3: https://dese.mo.gov/sites/g/files/zuston521/files/media/pdf/2021/04/curr-math-mls%20expanded-expectaions-grade-7.pdf

Validation includes the existing complete student flow and a focused event test for this budget item: a smaller valid session count is rejected as the full boundary; a reversed sign is rejected; x ≤ 12 is accepted; the full answer is displayed and survives storage/reload.
